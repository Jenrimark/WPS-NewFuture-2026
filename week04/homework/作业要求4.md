**一、项目背景**

在日常生活中，电费并非简单的“单价 x 数量”。它涉及阶梯电价、峰谷时段、限额和奖励规则以及复杂的计算。本项目要求学生在率先熟悉并开发 Go 基础的内容后，以利用基础类型、流程控制等内容，实现一个严谨的计算逻辑抽象。

**二、核心业务需求**

- **基础阶梯规则：**
  - 第一档：0 - 200 度（单价：0.6 元 / 度）
  - 第二档：200 - 400 度（超过部分单价：0.8 元 / 度）
  - 第三档：400 度以上（超过部分单价：1.2 元 / 度）
- **峰谷平调节因子：**
  - 高峰时段（8:00-22:00）总费率增加 10%。
  - 低谷时段（22:00-次日 8:00）总费率减少 20%。
- 使用 `init()` 函数初始化系统，并在控制台打印出当前的“计费规则版本号”和“系统的初始化时间”。
- 使用常量 (const) 定义所有的价格档位和浮点。
- 要求拆分为多个函数。
- 要求 main 模块中，执行一个循环，先引导用户输入用电量（比如 400.00），再引导用户输入用电时段（比如 14:00），计算后，打印出如下信息：

Bash

```
--- 账单明细 ---
用电总量：400.00 度
当前时段：14:00 点
最终电费：XX.XX 元
```

输入代码参考：

Go

```
package main

import (
    "fmt"
)

func main() {
    var num1, num2 int
    fmt.Print("请输入第一个整数，用空格分隔：")
    fmt.Scanln(&num1)

    fmt.Print("请输入第二个整数，用空格分隔：")
    fmt.Scanln(&num2)

    fmt.Printf("你输入的整数是：%d 和 %d\n", num1, num2)
}
```

- 要求针对计算函数编写单元测试（可利用结构体、数组切片等做一些典型值的测试）。
