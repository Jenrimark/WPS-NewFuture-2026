课堂练习：Gin + gRPC + SQLite 文件服务
一、项目目标
本次作业要求同学们完成一个简单的文件上传系统。
整个系统拆分为两个独立服务：
1. Web 服务（Gin）
2. 文件服务（gRPC）用户通过 Web 服务上传文件。
Web 服务负责：
1. 接收 HTTP 请求
2. 保存文件到本地
3. 计算文件 hash
4. 调用 gRPC 文件服务保存文件记录文件服务负责：
1. 提供 gRPC 接口
2. 使用 SQLite 保存文件记录
3. 查询文件列表本次作业重点是：
HTTP → Gin → gRPC → SQLite完整打通整个工程链路。

三、必须实现的 HTTP 接口 

批量上传文件接口
POST /api/files/uploads
接口流程：
1. 接收上传文件
2. 读取文件内容
3. 计算文件 hash
4. 基于 hash 生成新文件名
5. 保存文件到 uploads 目录（不要上传到git,使用.gitignore忽略）
6. 调用 gRPC 服务保存文件记录
7. 返回结果注意：原始文件名也要存储到数据库中。
返回示例
{
  "id": 1,
  "original_name": "test.png",
  "stored_name": "a8f7c1.png",
  "size": 102400,
  "mime_type": "image/png",
  "path": "uploads/a8f7c1.png"
}---
获取文件列表接口
GET /api/files
返回示例
[
  {
    "id": 1,
    "original_name": "test.png",
    "stored_name": "a8f7c1.png",
    "size": 102400,
    "mime_type": "image/png",
    "path": "uploads/a8f7c1.png"
  }
]---
下载文件接口
GET /api/files/download/:id接口流程：
1. Web 服务收到下载请求
2. 调用 gRPC 文件服务查询文件记录
3. 根据文件记录获取本地文件路径
4. 返回文件内容要求：
1. 必须通过文件 ID 下载
2. 不允许直接暴露 uploads 目录
