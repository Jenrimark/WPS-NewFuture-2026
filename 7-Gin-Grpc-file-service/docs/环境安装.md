# 开发与运行环境安装

本仓库为 **双模块**：`file-web`、`file-service`，proto 为独立模块 `proto/`（生成代码在 `proto/gen`）。按顺序安装即可在本机跑通 `make proto`、`go build`、`go run`。

## 1. Go

- **版本**：**1.22 或以上**（与 `go.mod` 中 `go 1.22` 一致）。
- **验证**：`go version`

### macOS

```bash
brew install go
# 或从 https://go.dev/dl/ 安装官方 pkg
```

安装后将 Go 的 bin 加入 PATH（官方安装包一般会配置；Homebrew 同理）：

```bash
echo 'export PATH="$(go env GOPATH)/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

### Linux（Debian/Ubuntu 示例）

```bash
sudo apt update
sudo apt install -y golang-go build-essential
# 若仓库 Go 过旧，请改用官方 tarball 或 backports
echo 'export PATH="$(go env GOPATH)/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc
```

### Windows

建议使用 **WSL2（Ubuntu）** 按本文 Linux 步骤安装，最接近课堂环境。若坚持原生 Windows，需自行安装 Go，并保证 `go`、`gcc`（SQLite 需要）在 PATH 中。

---

## 2. Protocol Buffers 编译器（protoc）

修改 `proto/file.proto` 后需要 `protoc` 生成 Go 代码。

### macOS

```bash
brew install protobuf
protoc --version
```

### Linux（Debian/Ubuntu）

```bash
sudo apt install -y protobuf-compiler
protoc --version
```

若版本过旧导致插件报错，可从 [protobuf releases](https://github.com/protocolbuffers/protobuf/releases) 下载较新的预编译包。

---

## 3. Go 的 protoc 插件

生成 `*.pb.go` 需要这两个插件，且需能在 PATH 里找到（通常在 `$(go env GOPATH)/bin`）：

```bash
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
```

**验证**：

```bash
which protoc-gen-go protoc-gen-go-grpc
protoc-gen-go --version
```

若 `which` 找不到，确认已执行上一节的 `GOPATH/bin` PATH，并重新打开终端。

---

## 4. SQLite（file-service，CGO）

`file-service` 使用 `github.com/mattn/go-sqlite3`，需要 **CGO 开启** 且系统上有 **C 编译器**。

### macOS

安装 Xcode Command Line Tools（含 `clang`）：

```bash
xcode-select --install
```

### Linux

```bash
sudo apt install -y build-essential
```

### 验证

```bash
go env CGO_ENABLED   # 通常为 1；若为 0，可执行: export CGO_ENABLED=1
```

---

## 5. 首次克隆项目后（依赖与 proto）

在仓库根目录 `gin-grpc-file-service/` 下：

```bash
# proto 模块
cd proto && go mod tidy && cd ..

# 生成 Go 代码（需 protoc + 两个插件已就绪）
make proto

# 两个业务模块
cd file-web && go mod tidy && cd ..
cd file-service && go mod tidy && cd ..
```

编译自检：

```bash
cd file-web && go build -o /dev/null ./... && cd ..
cd file-service && go build -o /dev/null ./... && cd ..
```

## 6. 可选：一键检查环境

在项目根目录执行（需赋予执行权限：`chmod +x scripts/check-env.sh`）：

```bash
./scripts/check-env.sh
```

脚本会检查 `go`、`protoc`、插件、`gcc/clang`、以及能否解析 `go.mod`。

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| `protoc-gen-go: program not found or is not executable` | 执行 `go install ...`，并把 `$(go env GOPATH)/bin` 加入 PATH |
| `undefined: grpc.SupportPackageIsVersion9` 等版本不匹配 | `go mod tidy`，必要时对齐 `google.golang.org/grpc`、`protobuf` 版本 |
| SQLite 链接失败 / `cgo` 报错 | 安装 `build-essential`（Linux）或 Xcode CLT（macOS），并设置 `CGO_ENABLED=1` |
| `replace local.dev/ginfilepb => ../proto` 找不到模块 | 必须在 **`file-web` / `file-service` 目录内** 执行 `go build`，或在根目录用 `-C` 指向子模块；不要在脱离 `proto` 兄弟目录的路径单独拷贝子目录编译 |

## 8. 运行所需环境变量（备忘）

| 变量 | 作用 | 默认 |
|------|------|------|
| `FILE_SERVICE_LISTEN` | gRPC 监听 | `:50051` |
| `FILE_SERVICE_DB` | SQLite 文件路径 | `data/files.db`（相对 `file-service` 工作目录） |
| `FILE_SERVICE_ADDR` | Web 连接 gRPC 地址 | `localhost:50051` |
| `HTTP_ADDR` | HTTP 监听 | `:8080` |
| `UPLOAD_ROOT` | 上传根目录 | 当前目录 |
| `MAX_UPLOAD_BYTES` | 单文件最大字节 | `33554432`（32 MiB） |

先启动 `file-service`，再启动 `file-web`。详见根目录 `README.md` 中的运行与 curl 示例。
