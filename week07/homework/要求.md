一、作业说明
实现一个在线海报设计器。页面采用三栏布局（左侧素材面板 + 中间画布区 + 右侧属性面板），支持向画布中添加文本、形状、图片等元素，并对其进行编辑和排版。
👋自行查找项目中用到的图标或素材即可，不要求完全一致。 
二、技术要求
• Vite
• React
• TypeScript
• Tailwind CSS
• Go、Gin、GORM、SQLite
三、功能需求
1.  登录/注册
系统在用户未主动退出前，应提供连续多日的可用会话体验。区分不同用户的海报信息并存储到后端。
满足接口
POST /api/register  { username, password }
POST /api/login      { username, password }
2.  页面布局
• 顶部工具栏：Logo、标题、撤销/重做按钮、退出登录、下载
• 左侧素材面板：通过竖向 Tab 切换「文本」「形状」「图片」三个面板
• 中间画布区：可缩放的画布，底部有缩放百分比控制（+/-按钮和输入框）
• 右侧属性面板：根据当前选中内容动态切换，未选中元素时显示画布相关属性，选中元素时显示对应元素的属性
3. 画布功能
• 默认尺寸 600×800px，支持自定义修改宽高（带锁定宽高比功能）
• 画布背景支持两种模式：纯色（颜色选择器 + 推荐色板）和贴图（上传图片作为背景）
• 支持「重置背景」恢复默认
4. 文本元素
• 点击「添加文本」后，在画布上单击或拖拽绘制文本框
• 文本选中后右侧显示属性面板，支持以下编辑：
    ◦ 字体选择、字号调整、文字颜色
    ◦ 样式：加粗、斜体、下划线、删除线
    ◦ 对齐方式：左对齐、居中、右对齐
    ◦ 字间距、行间距（滑块 + 数值输入）
    ◦ 透明度调整
    ◦ 阴影效果（开关控制）
• 单击文本可直接编辑文字内容
5. 形状元素
• 形状素材分为三个分类标签：「基础」「节日」「其它」
• 素材以 SVG 图片形式展示在左侧面板中，点击后在画布上单击或拖拽放置
• 选中形状后右侧显示属性面板：背景色修改、描边、阴影
6. 图片元素
• 提供预设图片，点击图片，可直接在画布中拖拽出选中的图片，右侧可编辑相关属性（参考上图）
• 支持选择本地图片，上传到阿里 OSS（前端直传，私有读取）
• 支持 AI 生成图片（后端提供中间接口），使用阿里云百炼相关模型即可
7. 元素通用操作
• 选中元素后显示选中框（虚线边框 + 控制手柄）
• 支持拖拽移动元素位置，拖拽时显示智能对齐辅助线（如画布中心线、与其他元素的对齐线）
• 支持通过手柄缩放元素大小
• 支持旋转元素（旋转手柄）
• 右键弹出菜单：支持图层上移、下移、置顶、置底
• 排版功能：水平居中、垂直居中等
8. 撤销与重做
• 记录用户操作历史，支持撤销和重做
• 无可撤销/重做操作时按钮置灰
9. 下载导出
• 点击右上角下载按钮，将画布内容导出为 PNG 格式的图片
